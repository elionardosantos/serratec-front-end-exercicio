### 1 - Crie uma página HTML chamada `index.html` com uma breve apresentação pessoal. A página deve conter informações sobre você, seus interesses e uma imagem representativa.

#### Requisitos: A página deve conter:
- Um título principal com seu nome
- Um parágrafo falando sobre você
- Uma lista com pelo menos 3 hobbies ou interesses
- Uma imagem
- Um link para uma rede social, GitHub ou LinkedIn

#### Requisitos de CSS: A página deve ter:
- Cor de fundo
- Título com cor diferente do texto
- Imagem com largura definida
- Espaçamento interno ou externo usando padding ou margin
